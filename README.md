# Secure File Encryptor Shredder

A secure file encryption and shredding utility for protecting sensitive data.

## Features

- File encryption with strong cryptographic algorithms
- Secure file shredding to prevent recovery
- Fast and efficient processing
- Command-line interface

## Getting Started

### Requirements

- .NET Framework or .NET Core
- Windows, Linux, or macOS

### Installation

1. Clone the repository
2. Build the project using your .NET build tools
3. Run the executable from the command line

## Usage

The utility provides encryption and secure deletion functionality:

- Encrypt files to protect sensitive information
- Shred files securely to prevent data recovery
- Process single files or batch operations

## How It Works

- Files are encrypted using industry-standard algorithms
- Shredding overwrites file data multiple times
- Temporary data is securely removed from memory

## Security

- Uses proven cryptographic methods
- Secure memory handling
- No recovery of shredded files
